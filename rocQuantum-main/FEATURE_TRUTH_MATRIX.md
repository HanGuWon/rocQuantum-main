# Feature Truth Matrix

Evidence refresh: 2026-07-31

Released comparison baselines: cuQuantum SDK `26.06.0` (cuStateVec `1.14.0`, cuTensorNet `2.13.0`, cuDensityMat `0.6.0`, cuPauliProp `0.4.0`, cuStabilizer `0.4.0`), CUDA-Q `0.15.0`, and CUDA-QX `0.6.0`. CUDA-QX 0.6 targets the CUDA-Q 0.14 release line, so its compatibility axis is kept separate from CUDA-Q 0.15.

Evidence ladder, from weakest to strongest:

1. `source-present`: relevant source, build graph, signature, explicit guard, or absence evidence was inspected.
2. `host-contract-tested`: reproducible CPU/mock/reference tests exercise the stated host behavior.
3. `native-single-GPU-verified`: an actual AMD GPU artifact verifies the native path.
4. `native-multi-GPU-verified`: an actual multi-GPU run crosses device/rank boundaries.
5. `performance-verified`: retained native benchmark data supports the performance claim.

The matrix is conservative. This workstation has no AMD GPU or ROCm runtime, so no row is promoted to a native or performance stage by this refresh. A `source-present` native row means that implementation source exists; it does **not** mean that the HIP path has been executed successfully. `host-contract-tested` is used only for host-visible behavior covered by the CPU/mock suite.
